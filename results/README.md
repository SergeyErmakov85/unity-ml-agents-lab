# results/ — прогоны обучения

Каталог **не коммитится** (`.gitignore`), кроме этого файла. Здесь лежат
артефакты запусков: логи TensorBoard, чекпойнты, экспортированные модели.

## Структура (требование 11.1)

```
results/
└── E##_<Name>/
    └── <algo>/
        └── <YYYYMMDD-HHMMSS>_seed<k>/
            ├── tb/             логи TensorBoard
            ├── ckpt/           чекпойнты обучения
            ├── onnx/           экспортированные модели этого прогона
            ├── config.yaml     точная копия конфига, с которым запускались
            ├── env_info.json   размерности пространств, режим подключения к Unity
            ├── metrics.json    последние значения всех записанных тегов
            └── pip_freeze.txt  слепок окружения
```

Каталог создаётся не вручную, а вызовом
`labrl.logging.run_dir.create_run_dir(env_id, algo, seed)`.

## Просмотр

```powershell
.\scripts\tb.ps1                        # все примеры
.\scripts\tb.ps1 -EnvId E03_RollerBall  # одна среда
```

## Что попадает в репозиторий

Ничего из `results/`. Модель, признанная итоговой для примера, копируется
в `unity/MLAgentsLab/Assets/Envs/E##_<Name>/Models/` — вот она коммитится
(при размере до 50 МБ; больше — только через Git LFS и отдельный ADR, п. 16.6).

Сводные числа по всем прогонам живут в `docs/RESULTS.md`, а не здесь.
